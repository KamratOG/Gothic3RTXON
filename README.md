# Gothic3RTXON
Gothic 3 + RTX. Play Gothic 3 in graphics like on the pre-rendered Alpha screenshots, but in real-time.

++

Gothic3 RTXON v0.1 by Kamrat
Released 02/2026
======|

Morra!

The purpose of this mod is to hype up the graphics of 2006's Gothic 3: 20 years forward.
Now it utilizes raytracing techniques with reflections and a completely new light distribution system,
with little to no performance usage. Hence the name RTX ON. 
Play Gothic 3 in graphics like on the pre-rendered Alpha screenshots, but in real-time.

Now you can enjoy this better-than-Skyrim sandbox in a completely new form.
No interface bugs typical for your usual enb & reshade enhancements. I've got it covered: rest assured.

Now install the mod and go do something useful, morra!

======|
Requirements:
1)ReShade (included in the folder. Don't have to go to their site)
[if the mod doesn't work, install their reshade first though].

2)Parallel Universe Patch (most recent version; as it doesn't replace the d3d9.dll
and therefore it's compatible with my mod).
======|

[X] How to install?
Copy the contents of "Insert into G3 main folder" catalog into the main G3 folder 
and replace everything if Windows asks you to do so. DONE. If you want to uninstall the mod,
delete all the new files (or just d3d9.dll).

[X] INSTRUCTIONS: HOW TO USE
Toggle RTX ON/OFF by PageUp.
Toggle GUI for configuration by Home.
